# 聚会游戏 Party Night · 酒吧聚会社交导演

一桌 4–5 个人、一台手机轮着传——它按你们的关系深度和接受尺度发题，谁不想聊的话题提前关掉，就不会被发到。

[English](./README.en.md) · [在线打开](https://party-night-v1-2.vercel.app/)

## 这是什么

一个给酒吧小桌用的社交破冰工具，主持人持机、逐人递手机作答。它不做「更敢玩」的刺激题，而是用一套可复述、有信息增量的题，让同桌的人真的多了解彼此。

核心是**边界先于内容**：开局前每人可以关掉自己不想碰的精确雷区，任何一人关闭，该类题就不会出现在这一局；敏感内容还有实时的 Consent 门禁。

## 能做什么

- **组局与轮次**：设定人数与关系类型，按 20 / 25 轮推进，每轮一张卡。
- **逐人递机作答**：一次只有一个人看题与作答，答完交给下一位。
- **关系与尺度分轴**：Heat（关系推进）与 Intensity（尺度）分开计算，低尺度也能出有深度的题。
- **精确雷区过滤**：题面按精确标签匹配，任一参与者关闭即禁出该题，而不是只在设置里写一句免责声明。
- **Consent 门禁**：涉及敏感边界的卡需要当场确认，拒绝即跳过，不解释、不追问。
- **固定题库主线**：正式局使用已冻结的固定题库，卡的可追溯来源会被校验；AI 动态出题当前默认关闭且不可绕过。
- **离线与恢复**：局面快照可恢复，断网也能继续。
- **自包含版**：提供可直接打开的静态版本，适合没有部署环境时使用。

## 怎么跑起来

需要 Node.js 20+ 与 npm。

```bash
npm install
npm run dev            # 本地开发
npm run build          # 生产构建
npm run build:export   # 静态自包含导出
npm test               # vitest 单元测试
npm run test:e2e       # Playwright 端到端
npm run typecheck
```

### Android 壳（Capacitor）

```bash
npm run android:sync     # 同步 Web 产物到原生工程
npm run android:release  # 构建 release 包（签名与版本规则见 docs）
```

### AI 开关

正式主线默认 `AI_MAINLINE_ENABLED=false`，服务端、组局跳转与出题函数入口都会拒绝生成请求；恢复 AI 需要先满足固定题库的验收门槛并由人工批准，详见 `docs/pm/PRODUCT_PLAN_V2.2-FIXED-CONTENT-FIRST.md`。

## 数据与隐私

- 作答内容只用于本局推进，不上传、不做用户画像。
- 局面快照只保存在本机；没有账号体系。
- 仓库内题库为固定内容，不含真人作答记录。

## 已知限制

- AI 动态出题暂停中；正式局只走固定题库。
- 当前以 4–5 人酒吧桌为主要场景，人数与场景扩展尚未验收。
- 固定题库仍在补齐，部分主题的可玩轮次有限，「洗牌再玩」在无合法卡时会隐藏。
